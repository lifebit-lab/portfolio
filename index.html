StockAIコンパス

日本株を財務・成長性・テクニカルで評価する判断支援ツール

財務健全性・成長性・テクニカル指標を統合した100点満点スコアで日本株を評価。下落が市場全体か個別企業の問題かを、ルールベースで自動分類します。

※投資助言ではなく、判断材料の提供を目的としています。

  • Next.js
  • TypeScript
  • J-Quants API
  • Yahoo Finance
  • Recharts
StockAIコンパスを開く↗
使い方
  1. 銘柄コード（例：7203）を入力して検索
  2. 財務健全性・成長性・収益性・テクニカルの各スコアを確認
  3. 下落理由（市場調整 vs 企業固有問題）の自動判定を参照
  4. スクリーニングでROE・PER・配当利回りから銘柄を絞り込む
仕組み

銘柄コードを入れると、2つの市場データから指標を集め、100点満点のスコアに組み立てます。

  1. 利用者銘柄コードを入力

  4. 期を補完成長率を補うYahoo Finance
  5. 6観点で採点スコアを算出財務・成長・収益・還元・割安・テクニカル
  6. 分類下落理由ルールベースで分類
  7. グラフ化結果を表示Recharts

Aurora Memoria

記憶の極光 — 光を描き、記憶を残し、やがて消えていく

夜空に触れると記憶が光になる。マウス・タッチで描いた線がオーロラのように漂い、時間とともにゆっくり薄れていく没入型インタラクティブ体験。Web Audio API によるアンビエント音響も内蔵。

  • Three.js
  • WebGL
  • GLSL Shader
  • Web Audio API
Aurora Memoriaを体験する↗
使い方
  1. 夜空をクリック・なぞってオーロラを描く
  2. 下の欄にことばを入力すると光のログに浮かぶ
  3. 記憶は約150秒でゆっくり薄れていく
  4. 「忘却の風」ボタンで全記憶を解放
仕組み

夜空をなぞると、その軌跡が光のリボンになります。描いた記憶は150秒かけて静かに薄れていきます。

  1. 来訪者マウス / タッチ
  2. なぞる軌跡を取得座標の列
  3. 曲線にする曲線を生成CatmullRomCurve3
  4. 帯にする光のリボンShaderMaterial
  5. 加算合成夜空に重ねるThree.js r128
  6. 150秒かけてゆっくり消えるlifeSeconds: 150
  7. 同時に環境音Web Audio API

04 EXPERIMENTS

IDEAS ARE CHEAP.
EXPERIMENTS
MAKE THEM REAL.

作品の中で実際に採用した、設計上の判断の記録。

  1. LOG—08 / CONFIDENCE

    確かなことだけを、確かだと言う。

    バリアフリー乗換ガイドでは、各情報に「確実／推定／要確認」の確信度を付け、号車案内には確かな情報だけを使う。間違った案内は、案内がないことより利用者を困らせるからです。

  2. LOG—05 / IMPERMANENCE

    消えることを、設計する。

    Aurora Memoriaの記憶は約150秒でゆっくり薄れていきます。保存するのではなく、余韻を残すこと自体を体験の中心に置きました。

  3. LOG—03 / RESTRAINT

    AIに、断定させない。

    StockAIコンパスは銘柄を推奨しません。スコアと下落理由の判定は「判断材料」として示し、最後の判断は使う人に委ねる設計です。

  4. LOG—04 / FRICTION

    受け取る側に、手間をかけさせない。

    Okuribaのお便りは、URLひとつで届きます。受け取る人はアカウント登録不要。有効期限は90日に区切っています。
